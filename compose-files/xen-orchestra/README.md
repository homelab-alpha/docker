# Xen Orchestra

A web interface to manage XCP-ng and XenServer hosts.

- **Upstream project**:
  [Xen Orchestra Docker image](https://github.com/ronivay/xen-orchestra-docker)
- **Documentation**:
  [Xen Orchestra on homelab-alpha.nl](https://homelab-alpha.nl/docker/compose-info/xen-orchestra/)

## Quick Start

> [!NOTE]
>
> Requires Docker Compose 2.24.0 or later.

1. Start the stack:

   ```bash
   docker compose up -d
   ```

## Default Web Access

Access the Xen Orchestra web interface using the following URL:

```bash
http://your-ip-address:3006
```

## Default Login Credentials

**Username**:

```bash
admin@admin.net
```

**Password**:

```bash
admin
```

> [!IMPORTANT]
>
> **For security reasons, it is strongly recommended that you change the default
