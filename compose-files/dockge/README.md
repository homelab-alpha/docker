# Dockge

A web interface to manage Docker Compose stacks.

- **Upstream project**: [Dockge](https://github.com/louislam/dockge)
- **Documentation**:
  [Dockge on homelab-alpha.nl](https://homelab-alpha.nl/docker/compose-info/dockge/)

## Quick Start

> [!NOTE]
>
> Requires Docker Compose 2.24.0 or later.

1. Start the stack:

   ```bash
   docker compose up -d
   ```

## Default Web Access

Access the Dockge web interface using the following URL:

```bash
http://your-ip-address:3005
```

## Default Login Credentials

> [!NOTE]
>
> On the first visit, Dockge asks you to create the admin account.

**Username**: Created during setup

**Password**: Created during setup

> [!IMPORTANT]
>
> **For security reasons, it is strongly recommended to create a strong username
> and password during the setup.**
